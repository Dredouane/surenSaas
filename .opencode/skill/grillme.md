\---\nname: grillme\ndescription: Use ONLY when the user wants to grill a plan and see if it's actually runnable, or if they want to test the execution of a plan.\n---\n\n# Grill Me Skill\n\nThis skill helps you test a plan before committing to it. It works by:\n\n1.  **Validating the Plan:** It checks if the plan is coherent, executable, and adheres to best practices.\n2.  **Simulating Execution:** It can simulate the execution of the plan by generating the necessary code and verifying its structure.\n3.  **Identifying Issues:** It helps pinpoint potential problems, missing dependencies, or inconsistencies in the plan.\n\n## Usage\n\nWhen a user provides a plan or asks to test a plan, use this skill to:\n\n1.  **Analyze the Plan:** Understand the steps, the tools involved, and the expected outcomes.\n2.  **Generate Code:** Create placeholder code or validate existing code snippets against project conventions.\n3.  **Check Dependencies:** Identify any missing libraries or tools required for the plan.\n4.  **Provide Feedback:** Offer a detailed report on the plan\'s viability and suggest improvements.\n\n**Example Workflow:**\n\nUser: \"Test this plan: [Plan details]\"\n\nAgent: Use `grillme` skill. Provide the plan to the skill.\n\nSkill Output: A report on the plan\'s validity, generated code snippets (if applicable), and potential issues.\n
