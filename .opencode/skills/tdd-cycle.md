Skill: TDD Cycle (Red-Green-Refactor)
Objectif : Ne jamais "dépasser ses phares" (don't outrun your headlights).
Action : Pour toute implémentation, suis strictement cet ordre :

RED : Écris un seul test unitaire décrivant un comportement attendu. Demande-moi de l'exécuter.

GREEN : Une fois le test échoué, écris le code minimal pour le faire passer.

REFACTOR : Propose une amélioration de la structure (Deep Modules) sans changer le comportement.
Interdiction : Ne génère pas le test ET le code dans le même message. Attends mon retour entre chaque étape.
